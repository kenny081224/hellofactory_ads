# 새 캠페인 구조 설계안

현재 구조와 새 구조의 차이, 그리고 왜 그렇게 바꾸는지를 정리합니다.
실제 설정값은 `campaigns/plan.yaml` 에 있고, 업로드 파일은
`python3 scripts/make_editor_csv.py` 로 생성합니다.

## 1. 현재 구조의 문제

들으신 내용 기준으로 현재는 **캠페인 1개 안에 비상벨 검색어 묶음 + 광고 2개**,
도착지는 스마트스토어 상품 링크입니다. 여기서 나오는 구조적 문제는 세 가지입니다.

1. **의도가 다른 검색어가 한 광고그룹에 섞여 있음.**
   "장애인화장실 비상벨"(법으로 설치해야 하는 시설 담당자)과 "비상벨"(뜻·소리·
   가격까지 뒤섞인 광의 검색)은 완전히 다른 사람입니다. 같은 광고그룹에 두면
   광고 문안이 어느 쪽에도 맞지 않게 되고 CTR·품질평가점수가 함께 내려갑니다.
2. **광고가 2개뿐.** 반응형 검색광고는 헤드라인 조합을 학습해서 성과를 냅니다.
   광고그룹당 RSA 1개 + 헤드라인 12~15개가 기준선입니다.
3. **제품이 섞일 위험.** 비상벨(시설 관리자 B2B/B2G)과 헬로클릭(교사·학교)은
   구매자·구매 절차·예산 주기가 전혀 다릅니다. 예산과 입찰을 분리해야 합니다.

## 2. 새 구조

```
계정
├── [검색] 비상벨 | 법정설치          예산 45%   ← 의도가 가장 명확, 전환 단가 최저 예상
│   ├── 장애인화장실 비상벨            정확+구문
│   ├── 공중화장실 비상벨              정확+구문
│   └── 설치 의무·기준 (정보탐색)      구문, 입찰 낮게
│
├── [검색] 비상벨 | 일반·시설별        예산 25%
│   ├── 무선 비상벨                    정확+구문
│   ├── 시설별 비상벨 (병원/학교/경비실…)  구문
│   ├── 가정·케어 호출벨                구문
│   └── 스마트폰 수신 비상벨 (차별점)    구문
│
├── [검색] 브랜드 | 헬로벨·헬로클릭     예산 5%    ← 방어용. CPC 싸고 전환율 최고
│   ├── 브랜드 - 헬로벨/헬로팩토리
│   └── 브랜드 - 헬로클릭
│
├── [검색] 헬로클릭 | 교육             예산 15%   ← 검색량이 얇아 소액으로 탐색
│   ├── 학생응답시스템
│   ├── 수업 참여 도구
│   ├── 퀴즈·골든벨 버저
│   └── 학교 도입·렌탈
│
└── (예비 10%)  4주 뒤 성과 확인 후 잘 되는 곳에 투입 / P-Max 테스트
```

## 3. 설계 원칙

| 원칙 | 이유 |
| --- | --- |
| 광고그룹 = 하나의 검색 의도 | 광고 문안·랜딩·입찰을 그 의도에 딱 맞출 수 있음 |
| 시작은 정확일치 + 구문일치만 | 광범위 검색은 전환 데이터가 쌓인 뒤에 열어야 안전 |
| 광고그룹당 키워드 5~12개 | 너무 적으면 노출이 안 나오고, 많으면 문안이 흐려짐 |
| 광고그룹당 RSA 1개 (헤드라인 8~15) | Google 학습에 필요한 최소 조합 수 확보 |
| 제외 키워드는 캠페인 단위 목록으로 | 광고그룹마다 중복 관리하지 않기 위해 |
| 처음엔 '클릭수 최대화 + 상한 CPC' | 전환 데이터가 없는 상태에서 스마트 입찰은 실패함 |

## 4. 입찰 전략 전환 시점

```
1~4주차   클릭수 최대화 (상한 CPC 700원)      → 검색어·키워드 데이터 수집
5주차~    캠페인당 월 전환 15건 이상이면
          → 전환수 최대화 (타겟 CPA 설정)
전환가치가 정상 수집되면
          → 전환가치 최대화 (타겟 ROAS)
```

⚠️ 전제 조건: `docs/measurement.md` 의 전환 추적이 먼저 해결되어야 합니다.
전환이 잡히지 않는 상태에서 타겟 CPA를 켜면 Google이 아무 근거 없이 입찰합니다.

## 5. 기존 캠페인 처리

**바로 삭제하지 마세요.** 순서는 이렇습니다.

1. 새 캠페인을 `Paused` 상태로 업로드하고 키워드·문안·URL을 눈으로 검수
2. 기존 캠페인의 검색어 리포트를 마지막으로 내려받아
   `python3 scripts/search_terms.py` 로 제외 키워드를 뽑아 새 캠페인에 반영
3. 새 캠페인 `사용 설정` → 기존 캠페인 `일시중지`
   (같은 키워드가 양쪽에 있으면 서로 입찰 경쟁을 하게 됩니다)
4. 2주 뒤 성과 비교. 새 구조가 나쁘면 되돌릴 수 있게 기존 캠페인은
   **삭제하지 않고 일시중지 상태로 보존**합니다.

## 6. 광고 확장(애셋) — 반드시 함께 설정

RSA만으로는 광고 면적이 작습니다. 아래는 캠페인 단위로 한 번만 넣으면 됩니다.

- **사이트링크 4개**: `견적 문의` / `설치 사례` / `제품 라인업` / `자주 묻는 질문`
- **콜아웃 6개**: `배선공사 불필요` `당일 출고` `세금계산서 발행` `관공서 납품실적`
  `대량구매 할인` `설치 상담 무료`
- **구조화된 스니펫**: 유형 `제품` → 비상벨, 도움벨, 호출벨, 수신기, 경광등
- **전화번호 확장**: 전화 클릭을 전환으로 잡기 위해 필수
- **위치 확장**: 사업자 주소가 노출되면 관공서 담당자의 신뢰도가 올라갑니다
