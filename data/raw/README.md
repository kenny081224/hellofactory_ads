# 여기에 Google Ads 리포트 CSV를 넣으세요

`scripts/analyze.py` 와 `scripts/search_terms.py` 가 이 폴더를 읽습니다.
리포트 종류는 **파일명으로 먼저, 안 되면 컬럼 구성을 읽어서** 판별하므로
`report (3).csv` 같은 이름도 그대로 넣으면 됩니다.

> 파일 정리를 자동으로 하려면 `python3 scripts/browser_download.py` 를 켜 두세요.
> 크롬에서 받는 즉시 이 폴더로 옮겨줍니다. ([`docs/browser_download.md`](../../docs/browser_download.md))

아래는 파일명으로 인식되는 단어입니다.

| 필요한 리포트 | 파일명 예시 | 인식 키워드 |
| --- | --- | --- |
| 캠페인 실적 | `캠페인_2026-08.csv` | `캠페인` 또는 `campaign` |
| 광고그룹 실적 | `광고그룹_2026-08.csv` | `광고그룹` 또는 `adgroup` |
| 키워드 실적 | `키워드_2026-08.csv` | `키워드` 또는 `keyword` |
| **검색어 리포트** | `검색어_2026-08.csv` | `검색어` 또는 `searchterm` |

## 내보내는 방법

1. [Google Ads](https://ads.google.com) 접속
2. 왼쪽 메뉴에서 해당 화면으로 이동
   - 캠페인 → **캠페인**
   - 캠페인 → 광고그룹
   - 캠페인 → 검색 키워드 → **검색 키워드**
   - 캠페인 → 검색 키워드 → **검색어** ← 가장 중요
3. 기간을 **캠페인 시작일 ~ 어제** 로 설정
4. 표 위의 **열(컬럼)** 버튼 → 아래 항목을 모두 추가
   - 비용, 노출수, 클릭수, CTR, 평균 CPC
   - 전환수, 전환 가치, 전환당비용, 전환율
   - (캠페인 리포트에만) 검색 노출 점유율, 검색 손실 노출 점유율(예산),
     검색 손실 노출 점유율(순위)
5. 오른쪽 위 **다운로드 아이콘 → .csv** 선택
6. 받은 파일을 이 폴더에 넣기

## 실행

```bash
python3 scripts/analyze.py        # 전체 진단 리포트
python3 scripts/search_terms.py   # 제외/신규 키워드 후보
```

결과는 `reports/` 와 `campaigns/generated/` 에 생깁니다.

## 참고

- 인코딩(UTF-8 / UTF-16 / CP949)과 구분자(쉼표 / 탭)는 자동으로 처리됩니다.
- 리포트 맨 위의 제목·기간 행과 맨 아래 "총계" 행도 자동으로 걸러집니다.
- 컬럼 이름은 한국어·영어 둘 다 인식합니다.
- 이 폴더의 CSV는 `.gitignore` 로 커밋에서 제외됩니다 (계정 데이터 보호).
