# 애셋(광고 확장) 전략

애셋은 광고 면적을 넓히고 클릭 전에 궁금증을 해소해 줍니다. 같은 순위여도
애셋이 붙은 광고가 CTR과 전환율이 높습니다. **애셋 없이 RSA만 있으면 광고는
두 줄짜리로 나갑니다.**

```bash
python3 scripts/assets.py     # 애셋 실적 진단
```

## 1. 애셋 리포트 내려받기

두 개를 받아야 합니다. 성격이 다릅니다.

| 받을 것 | 경로 | 무엇을 알려주나 |
| --- | --- | --- |
| **RSA 애셋** | 광고 → 애셋 | 헤드라인·설명별 실적 등급 (최우수/양호/낮음/학습 중) |
| **확장 애셋** | 캠페인 → 애셋 | 사이트링크·콜아웃·스니펫·전화·이미지 보유 현황과 실적 |

내려받을 때 열(컬럼)에 **애셋 / 애셋 유형 / 필드 유형 / 실적 / 노출수 / 클릭수 /
CTR / 비용 / 전환수 / 전환 가치** 를 넣으세요. `실적` 열이 없으면 등급 분석이
안 됩니다.

`python3 scripts/browser_download.py` 를 켜 두면 파일명이 무엇이든 알아서
`data/raw/` 로 정리합니다.

## 2. 전환율을 올리는 애셋 — 우선순위

비상벨·헬로클릭 기준으로 효과가 큰 순서입니다.

### ★★★ 반드시

| 애셋 | 왜 |
| --- | --- |
| **전화** | 비상벨 문의는 상당수가 전화입니다. 전화 클릭을 전환으로 잡을 수 있어 측정 관점에서도 필수 |
| **사이트링크 4~6개** | 광고 면적이 가장 크게 늘어납니다. 설명 2줄까지 채워야 효과가 납니다 |
| **콜아웃 4~8개** | "배선공사 불필요", "세금계산서 발행" 처럼 **구매 장벽을 미리 없애는 문구** |
| **구조화된 스니펫** | 취급 품목을 한 줄로 보여줘 "여긴 전문업체구나"를 만듭니다 |

### ★★ 강력히 권장

| 애셋 | 왜 |
| --- | --- |
| **리드 양식** | 관공서·학교 대량 문의가 핵심인 비상벨에 특히 잘 맞습니다. 광고에서 바로 문의를 받아 랜딩 이탈을 없앱니다 |
| **이미지** | 제품이 눈에 보이는 하드웨어라 효과가 큽니다. (규격은 아래 3번) |
| **위치** | 사업자 주소 노출은 관공서 담당자 신뢰도에 직접 영향 |
| **비즈니스 이름·로고** | 헬로벨 브랜드가 광고에 노출되어 재방문 유입에 유리 |

### ★ 상황에 따라

| 애셋 | 판단 |
| --- | --- |
| **가격** | 헬로클릭은 "기본 세트 220,000원" 처럼 명확해서 잘 맞습니다. 비상벨은 구성별 편차가 커서 오히려 이탈을 만들 수 있으니 신중히 |
| **프로모션** | 상시 할인이 없다면 넣지 마세요. 비워두면 다른 애셋이 그 자리를 씁니다 |

문안은 `campaigns/assets.yaml` 에 이미 써 두었습니다.
`python3 scripts/make_editor_csv.py` 를 돌리면 아래가 생성됩니다.

```
06_sitelinks.csv              사이트링크 (캠페인별)
07_callouts.csv               콜아웃
08_structured_snippets.csv    구조화된 스니펫
```

전화·이미지·리드 양식·위치는 **Editor 로 올릴 수 없고** Google Ads 화면에서
직접 설정해야 합니다. 항목은 `campaigns/assets.yaml` 의 `manual:` 에 있습니다.

## 3. 이미지 애셋 규격

검색 캠페인용 이미지 애셋입니다.

| 비율 | 권장 크기 | 최소 크기 | 필수 |
| --- | --- | --- | --- |
| 정사각형 1:1 | 1200 × 1200 | 300 × 300 | ✅ |
| 가로형 1.91:1 | 1200 × 628 | 600 × 314 | 권장 |

- 형식: JPG / PNG / 정적 GIF, 파일당 **5MB 이하**
- 캠페인·광고그룹당 최대 20개
- 잘림에 주의: 같은 사진의 1:1 과 1.91:1 을 **따로 잘라서** 올리세요.
  자동 크롭에 맡기면 제품이 잘립니다.

### 승인되지 않는 것

- 이미지 안에 글자를 크게 넣은 배너형 (텍스트 비중이 크면 거부됩니다)
- 워터마크, 테두리, 콜라주, 여백이 큰 이미지
- 흐릿하거나 심하게 늘어난 이미지
- 로고만 있는 이미지 (로고는 로고 애셋으로 따로)

### 어떤 사진이 잘 먹히나 — 비상벨

1. **설치된 현장 사진.** 장애인화장실 벽면에 비상벨과 점자안내판이 붙어 있는 컷.
   "이렇게 생겼구나"가 즉시 전달되고 법정 설치 이미지와 연결됩니다.
2. **구성품 전체 컷.** 버튼 + 수신기 + 안내판을 흰 배경에 펼친 사진.
   "세트로 오는구나"를 보여줘 문의 전 이탈을 줄입니다.
3. **손으로 버튼을 누르는 클로즈업.** 크기 감이 잡힙니다.
4. **스마트폰 알림 화면.** 이게 경쟁사와의 차별점이라 반드시 한 장 넣으세요.

### 어떤 사진이 잘 먹히나 — 헬로클릭

1. **교실에서 학생들이 버튼을 든 장면.** (초상권 확인 필요)
2. **대시보드 화면 캡처.** 참여도가 그래프로 보이는 화면이 제품의 핵심입니다.
3. **기본 세트 구성품 컷** (수신기 1 + 디바이스 6).

## 4. 이미지 전달 방법

편한 쪽으로 주시면 됩니다.

### 방법 1 — 대화창에 그냥 첨부 (권장)

현재 쓰고 있는 이미지 파일을 이 대화에 그대로 올려 주세요.
바로 보고 아래를 짚어 드립니다.

- 작은 크기(모바일 광고 노출 크기)에서 제품이 식별되는지
- 텍스트 비중이 승인 기준을 넘지 않는지
- 1:1 로 잘렸을 때 핵심이 잘리지 않는지
- 4가지 권장 컷 중 무엇이 비어 있는지

### 방법 2 — 저장소에 넣기

PC에서 작업 중이라면 폴더에 넣고 커밋해 주세요.

```
assets/current/     지금 계정에 올라가 있는 이미지
assets/new/         새로 만든 이미지
```

```bash
cp ~/이미지/*.jpg assets/current/
python3 scripts/check_images.py       # 규격 검사
git add assets && git commit -m "현재 이미지 애셋 추가" && git push
```

> Google Drive 링크는 이 작업 세션에서 읽을 수 없습니다.
> (읽기 권한이 있는 Drive 도구가 연결되어 있지 않습니다)

## 5. 애셋 개선 루틴

애셋은 한 번 넣고 끝이 아닙니다.

| 주기 | 할 일 |
| --- | --- |
| 격주 | `python3 scripts/assets.py` → '낮음' 등급 **2~3개만** 교체 |
| 격주 | 교체한 문구를 `campaigns/ads.yaml` / `assets.yaml` 에도 반영 (계정과 저장소 일치) |
| 월 1회 | '최우수' 문구의 공통점을 뽑아 같은 결의 문구를 2~3개 추가 |
| 분기 | 이미지 애셋 교체 (계절·현장 사진 갱신) |

**하지 말 것**

- 한 번에 전부 교체 — 무엇이 효과였는지 알 수 없고 학습이 초기화됩니다
- '학습 중' 상태에서 판단 — 노출이 더 쌓여야 등급이 나옵니다
- 헤드라인 15개를 억지로 채우기 — 억지 문구는 '낮음'을 만들고 전체 조합 품질을 떨어뜨립니다.
  잘 쓴 10개가 억지 15개보다 낫습니다
