## 1. 그런데 더 중요한 발견 — 2년째 사실상 눈을 감고 달리는 중입니다

1년차 CPA 1,554원, 최근 2년 CPA 121,173원. **78배 차이**입니다.
이건 성과가 나빠진 게 아니라 **세는 대상이 바뀌었거나 추적이 끊긴 것**입니다.

1년차에 기록된 전환 5,295건은 전환당 가치가 1,349원이었습니다.
비상벨 객단가가 9만 원대인 걸 감안하면 실제 구매가 아니었습니다.
**그 저가치 전환이 2024년 8~9월 무렵 사라졌고, 이후 24개월 동안 전환은 29건뿐입니다.**

```
25개월 중 17개월이 전환 0건 — 합계 2,435,763원 (2년 지출의 69.3%)
2024-10, 11, 12 / 2025-02~11 / 2026-01, 02, 07, 08
```

특히 최근이 문제입니다.

| 월 | 비용 | 전환 |
| --- | ---: | ---: |
| 2026-06 | 163,254원 | **13** |
| 2026-07 | 175,176원 | **0** |
| 2026-08 | 168,905원 | **0** |

6월에 13건(검색 7 + P-Max 6)이 나오다가 7·8월에 동시에 0이 되었습니다.
두 캠페인이 **같은 달에 나란히** 0이 된 건 시장 변화보다 **태그 문제**를 먼저
의심해야 하는 패턴입니다. 344,081원이 측정 없이 나갔습니다.

**→ 다른 어떤 조치보다 이것부터입니다.**
Google Ads → 목표 → 전환 에서 각 전환 액션의 상태가
'최근 전환 기록됨'인지, '전환이 기록되지 않음'인지 확인하세요.

## 4. ⚠️ 이전 진단 정정 — '무선 호출벨'은 승자가 아닙니다

지난번에 **"'무선 호출벨'이 CPA 5,031원에 전환 57건으로 검색 전환의 61%"** 라고
말씀드리고 전용 광고그룹까지 만들었습니다. **이건 틀렸습니다.**

| 기간 | 비용 | 클릭 | 전환 |
| --- | ---: | ---: | ---: |
| 3년 전체 | 299,633원 | 357 | 63 |
| **최근 2년** | **41,502원** | **46** | **0** |

그 63건은 **전부 1년차의 저가치 전환**이었습니다. 1년차 계정 CPA가 1,554원이던
시기의 숫자라 실제 구매로 볼 근거가 없습니다.
`campaigns/plan.yaml` 에서 '최고 효율' 표기를 빼고 '전환 확인이 필요한 그룹'으로
내렸습니다.

같은 이유로 3년 기준에서 크게 보였던 **복지·돌봄 낭비(748,128원)도 대부분
1년차 문제**입니다. 최근 2년 기준으로는 59,048원(4%)에 불과합니다.

## 6. 광고는 25개월 동안 한 번도 안 바뀌었습니다


  전환 태그를 심을 수 없는 곳으로 트래픽을 보내는 중입니다

  광고 문안이 따라붙었습니다
