## 문제 1. 전환 정의가 깨져 있습니다 ★ 최우선

같은 제품을 파는 두 캠페인의 CPA가 **1,017원 vs 47,637원 — 47배** 차이입니다.
이건 성과 차이가 아니라 **서로 다른 것을 세고 있다**는 뜻입니다.

계산해 보면 명확합니다.

```
P-Max:  전환 5,221건 × 전환가치 7,344,108원  →  전환 1건당 1,406원
검색:   전환   103건 × 전환가치   139,523원  →  전환 1건당 1,354원
```

비상벨 객단가가 9만 원대라면 5,221건은 4.7억이어야 합니다. 실제 기록된
전환가치는 734만 원입니다. **즉 지금 '전환'으로 세고 있는 것은 구매가 아닙니다.**
페이지 조회나 스마트스토어 이동 클릭 같은 저가치 액션일 가능성이 큽니다.

**그래서 ROAS 0.64, CPA 2,205원 같은 숫자는 의사결정에 쓸 수 없습니다.**
예산을 어디로 옮길지, 입찰을 얼마로 할지 판단하는 근거가 통째로 오염돼 있습니다.

### 해야 할 일

1. Google Ads → 목표 → 전환 → 각 전환 액션의 **소스·카테고리·값·집계 방식**을 확인
2. 구매가 아닌 액션은 **'주요 전환'에서 해제** (보조 전환으로만 두기)
3. 자사몰에 제품별 구매 전환 태그 설치 → [`tagging_hellobell.md`](tagging_hellobell.md)

랜딩 리포트를 보면 이미 **자사몰이 최대 도착지**입니다. 태그만 심으면 됩니다.

| 도착지 | 비용 |
| --- | ---: |
| hellobell.shop (product_no=45) | 3,821,447원 |
| smartstore.naver.com (3개 URL 합계) | 4,883,842원 |
| hellobell.shop (product_no=50) | 1,508,200원 |
| hellofactory.co.kr | 657,510원 |

도착지가 3곳으로 흩어져 있어 성과가 합산되지 않습니다. **자사몰로 통일**하면
측정이 되고 성과도 한곳에 쌓입니다.
