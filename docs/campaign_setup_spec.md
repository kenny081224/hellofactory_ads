작성 2026-08-30 · 헬로팩토리 (헬로벨 · 헬로클릭)

**기존 캠페인은 참고만 하고 처음부터 새로 세팅하는 것을 전제로 한 설정서입니다.**
화면에 그대로 입력할 수 있도록 값을 전부 확정해 두었습니다.

| 구성 | 수량 |
| --- | ---: |
| 캠페인 | 4개 |
| 광고그룹 | 9개 |
| 키워드 | 93개 (정확일치·구문일치만) |
| 제외 키워드 | 89개 |
| 반응형 검색광고 | 9개 (헤드라인 109개) |
| 월 예산 | 600,000원 (집행 510,000원 + 예비 90,000원) |

## 이 설정서의 전제

답을 아직 못 받은 항목은 아래 값으로 가정했습니다. 다르면 알려주세요.

| 항목 | 가정한 값 | 다르면 바뀌는 것 |
| --- | --- | --- |
| 월 예산 | 600,000원 | 캠페인 수와 광고그룹 수 (10장에 축소안) |
| 헬로클릭 렌탈 가격 | 광고에 표기하지 않음 | 가격 애셋 사용 여부, 헤드라인 1개 |
| 렌탈 문의 페이지 | **신규 제작 필요** | C3 캠페인 최종 URL |
| 지자체 납품 실적 | 있다고 가정하지 않음 | S1 헤드라인 '지자체 납품용 응급벨' 표현 |
| 교육(학교) 채널 | 브랜드 그룹에만 소액 유지 | B2 키워드 구성 |

> 지자체 실적이 실제로 없다면 `지자체 납품용 응급벨` 헤드라인은 빼세요.
> 근거 없는 실적 표기는 심사에서 거부되거나 신뢰를 잃습니다.

## 1. 0단계 — 세팅 전에 반드시 끝낼 것

**아래가 안 된 상태로 캠페인을 켜면 지난 2년과 같은 일이 반복됩니다.**
(최근 25개월 중 17개월이 전환 0, 2026년 7·8월은 344,081원 쓰고 전환 0)

### 1-1. 전환 추적 복구 및 신규 구축

| 전환 액션 이름 | 카테고리 | 값 | 집계 | 주요 전환 |
| --- | --- | --- | --- | :---: |
| `구매_헬로벨` | 구매 | 결제금액 | 모든 전환 | ✅ |
| `구매_헬로클릭` | 구매 | 결제금액 | 모든 전환 | ✅ |
| `견적문의_헬로벨` | 문의 제출 | 고정 30,000원 | 전환 1회 | ✅ |
| `대여문의_헬로클릭` | 문의 제출 | 고정 50,000원 | 전환 1회 | ✅ |
| `전화클릭` | 전화 통화 | 고정 20,000원 | 전환 1회 | ✅ |
| `장바구니담기` | 장바구니 추가 | 없음 | 전환 1회 | ❌ 관찰용 |

- 값은 잠정치입니다. 문의 성사율을 알게 되면 실제 값으로 교체하세요.
- **값을 0으로 두지 마세요.** 캠페인 간 비교가 불가능해집니다.
- 자사몰(Cafe24) 태그 설치 절차는 `docs/tagging_hellobell.md` 참고.

## 2. 계정 공통 설정

| 항목 | 값 |
| --- | --- |
| 캠페인 유형 | 검색 (전 캠페인 공통) |
| 목표 | 목표 설정 없이 캠페인 만들기 |
| 네트워크 | 검색 네트워크 **ON** / 검색 파트너 **OFF** / 디스플레이 확장 **OFF** |
| 위치 | 대한민국 |
| 위치 옵션 | **타겟 위치에 있는 사람** (관심 위치 제외) |
| 언어 | 한국어 |
| 예산 유형 | 일일 예산 |
| 입찰 전략 | **클릭수 최대화 + 최대 CPC 입찰가 한도** (1~4주차) |
| 광고 순환 | 실적이 우수한 광고 최적화 |
| 기기 입찰 조정 | 휴대전화 **-30%** / 태블릿 **-50%** / TV 화면 **-100%** |
| 광고 일정 | 월~금 08:00~20:00 / 토·일 10:00~18:00 |
| 일정 입찰 조정 | 토요일 **-50%** / 평일 08~09시 **-40%** |
| 최종 URL 확장 | **사용 안 함** |
| 자동 생성 애셋 | **사용 안 함** (초기 4주간) |

**근거**

- 검색 파트너 OFF: 최근 2년 P-Max 자동 게재위치 상위 12곳이 전환 0
- 모바일 -30%: 최근 2년 검색 CPA 모바일 92,901원 / PC 27,578원 (3.4배)
- 토요일 -50%: 176,246원 지출에 전환 0
- 08~09시 -40%: 837,254원 지출에 전환 1건
- 자동 생성 애셋 OFF: 초기에는 문안 성과를 깨끗하게 읽어야 함

### 캠페인별 전환 액션 지정 ★ 빠뜨리기 쉬움

**캠페인 → 설정 → 전환 → '이 캠페인에 대해 전환 액션 선택'**

| 캠페인 | 선택할 전환 액션 |
| --- | --- |
| C1, C2 (헬로벨) | `구매_헬로벨`, `견적문의_헬로벨`, `전화클릭` |
| C3 (헬로클릭) | `구매_헬로클릭`, `대여문의_헬로클릭`, `전화클릭` |
| C4 (브랜드) | 전부 |

이걸 안 하면 헬로클릭 캠페인이 헬로벨 매출을 자기 성과로 보고 최적화합니다.

## 8. 입찰 전략 전환 계획

```
1~4주차   클릭수 최대화 + 최대 CPC 한도
          목적: 검색어 데이터 수집. 전환 추적이 방금 복구된 상태라
                스마트 입찰에 넘길 학습 데이터가 아직 없습니다

5주차~    캠페인 월 전환 15건 이상  →  전환수 최대화 (타겟 CPA)
          헬로벨 목표 CPA 30,000원 / 헬로클릭 목표 CPA 50,000원

안정 후   전환가치가 실제 매출로 수집됨  →  전환가치 최대화 (타겟 ROAS)
```

**절대 하지 말 것**: 전환 데이터 없이 타겟 CPA·ROAS를 켜는 것.
근거 없이 입찰하며 예산만 소진합니다.

## 9. 실행 체크리스트

1. [ ] 전환 액션 6개 생성 + 자사몰 태그 설치 + 테스트 주문으로 검증

3. [ ] 제외 키워드 목록 3개 생성 (`공통_제외`, `헬로벨_제외`, `헬로클릭_제외`)
4. [ ] 캠페인 4개 생성 — 2장 공통 설정값 그대로 입력
5. [ ] 캠페인별 전환 액션 지정 (2장 마지막 표)
6. [ ] 광고그룹 9개 생성 + 키워드 93개 입력 (4장)
7. [ ] 제외 키워드 목록을 캠페인에 연결
8. [ ] RSA 9개 등록 (6장) — 헤드라인 1번 위치 고정 확인
9. [ ] 사이트링크·콜아웃·스니펫 등록 (7장)
10. [ ] 전화·리드 양식·위치·이미지 애셋 등록 (7-4, 7-5)
11. [ ] **일시중지 상태로** 전체 검수 — 키워드 오타, 최종 URL, 경로
12. [ ] 기존 캠페인 일시중지 → 새 캠페인 사용 설정 (같은 날 동시에)
13. [ ] 기존 캠페인은 **삭제하지 말고** 일시중지로 보존

> 12번을 같은 날 하는 이유: 기존과 새 캠페인이 같은 키워드로 동시에 돌면
> 서로 입찰 경쟁을 하게 되어 CPC가 올라갑니다.
