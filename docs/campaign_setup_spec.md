### 이 조사로 내린 결론 3가지

**① 브랜드 캠페인은 만들지 않습니다.**
자사 브랜드 검색은 기준의 4.5%(헬로벨), 헬로클릭은 데이터랩에 데이터가
아예 없습니다. 계정 기준으로도 2년간 브랜드 검색어 노출이 108회(0.41%)뿐입니다.
방어할 대상이 없어 별도 캠페인은 낭비이고, **광고그룹 하나로 충분합니다.**
반대로 경쟁사(씨스콜·링고벨) 검색은 기준의 **1.27배**로 자사의 28배입니다.

**② `원격 수신 비상벨` 계열은 전부 뺐습니다.**
제품의 핵심 차별점이지만 **사람들이 그 말로 검색하지 않습니다.**
데이터랩 0, 계정 2년 노출 0회. 키워드가 아니라 **광고 문안과 랜딩에서**
설명할 내용입니다. 문안에는 그대로 살려 뒀습니다.

**③ 헬로클릭은 검색 수요가 사실상 없습니다.**
무선투표기·전자투표기·청중응답시스템·골든벨 장비·행사 투표기·투표기 렌탈이
전부 기준의 0.005배 이하이고, 계정 2년 노출 합계가 55회입니다.
`전자투표`는 수요가 크지만(0.48배) **제도·서비스를 찾는 검색**이라
장비 구매 의도가 아닙니다.

> **검색 광고로 헬로클릭 렌탈 수요를 잡는 것은 어렵습니다.**
> 예산의 3%만 배정해 8주간 '정말 없는지' 확인하고, 없으면 검색을 접고
> 행사대행사 직접 영업·전시회·유튜브 같은 **수요를 만드는 채널**로
> 가야 합니다. 자세한 판단 기준은 11장.

## 7. 반응형 검색광고 문안

글자 수는 Google 실제 규칙(전각 2 / 반각 1, 헤드라인 30 · 설명 90)으로
전수 검증했습니다. 괄호 안이 계산된 글자 수입니다.

**공통**

- 광고그룹당 완성형 RSA **1개**로 시작
- **헤드라인 위치를 고정하지 않습니다.** 트래픽이 적은 초기에 고정하면
  조합 학습이 막히고 데이터가 분산됩니다 (v4 지적 반영)
- 광고그룹 누적 클릭 30회를 넘긴 뒤에 두 번째 메시지 방향을 테스트
- 최종 URL 은 광고그룹 의도와 정확히 맞는 랜딩으로 연결

### 광고 표현 금지 사항 ★

| 금지 | 이유 | 해제 조건 |
| --- | --- | --- |
| `낙상 자동 감지`, `자동 감지` | 제품은 **버튼을 눌러** 알리는 방식 | 해제 불가 |
| `119 자동 연결` | 기능이 확인되지 않음 | 기능 확인 시 |
| `생명을 지킵니다`, `안전을 보장` | 안전을 보장하는 단정 표현 | 해제 불가 |
| `거리 제한 없음` (조건 없이) | 인터넷 연결이 전제 | `수신기 앞에 없어도` 로 대체 |
| **`방수`, `IPX6`** | 헬로벨 자료에 방수 등급 없음 (IPX6는 헬로클릭 사양) | 헬로벨 실제 등급 확인 시 |
| **`배터리 2년`** | 헬로벨 자료에 배터리 수명 없음 (AAA 2년은 헬로클릭) | 실제 수명 확인 시 |
| **`A/S 보장`, `정품 보장`** | 자료에 A/S 조건 없음 | 보증 정책 확인 시 |
| **`납품 실적`, `관공서 학교 납품`** | 자료에 설치 사진은 있으나 실적 표기 없음 | 실적 확인 시 |
| **`세금계산서 발행`** | 자료 근거 없음 | 사실이면 즉시 사용 가능 |
| 학교·교실 이미지 (헬로클릭) | 이번 광고 타깃이 아님 | 해제 불가 |

> 굵게 표시한 5개는 **사실이면 쓸 수 있는 문구**입니다. 12장 6번에서
> 확인해 주시면 문안에 되살립니다. 지금은 근거가 없어 뺐습니다.

- 주요 전환 0건이고 비용이 목표 CPA 의 **1.5배**를 넘으면 키워드·검색어 축소

## 12. 승인이 필요한 항목

**설정 전에 아래만 확정하면 됩니다.** 1~3번이 없으면 목표 CPA 를 정할 수 없고,
목표 CPA 가 없으면 4주차 판정 기준이 성립하지 않습니다.

| # | 항목 | 없으면 생기는 일 |
| ---: | --- | --- |
| 1 | 헬로벨 개인 구매 평균 매출과 매출총이익 | 목표 CPA 산정 불가 |
| 2 | 헬로벨 시설 계약 평균 매출총이익, 문의→계약률 | 견적 문의의 기대가치 산정 불가 |
| 3 | 헬로클릭 구매·렌탈 평균 계약금액과 마진 | 8주 테스트 손익 판정 불가 |
| 4 | 실제 판매·렌탈·설치 가능 지역 | 지역 타겟 설정 불가 |
| 5 | 전화 응대 가능 시간 | 전화 애셋 일정 설정 불가 |
| 6 | **제품 사양 확인** — 헬로벨 방수 등급 / 배터리 수명 / A/S 보증 / 납품 실적 / 세금계산서 발행 | 해당 문구 5종을 문안에서 뺀 상태. 확인되면 되살림 (7장) |
| 7 | 헬로벨 개인·시설, 헬로클릭 구매·렌탈 랜딩 URL | 캠페인 활성화 불가 |
| 8 | **매장·식당용 호출벨도 판매하는가** | 판매한다면 `호출벨그룹_제외`(6-3)를 넣으면 안 되고, 오히려 키워드를 확장해야 함 |
| 9 | CRM 오프라인 전환 연동 가능 여부 | 견적·계약 전환 사용 여부 결정 |

### 전환 가치는 임의로 넣지 않습니다

근거 없이 `적격 문의 50,000원` 같은 고정값을 넣으면 나중에 자동입찰이
그 가짜 값을 기준으로 학습합니다. 1~3번이 확정될 때까지는 값을 비워 두고
**클릭수 최대화**로만 운영합니다.

```
문의 기대가치 = 문의→계약 전환율 × 평균 매출총이익
허용 CPA     = 문의 기대가치 × 허용 광고비 비율
손익분기 ROAS = 1 ÷ 매출총이익률      (예: 마진 40% → 250%)
```

실제로는 인건비·배송·설치·A/S 비용까지 넣어 회사 기준을 확정해야 합니다.
