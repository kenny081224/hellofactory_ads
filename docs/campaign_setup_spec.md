## 8. 입찰 전환 조건 · P-Max 시작 조건

### 검색 캠페인

```
1~4주차   클릭수 최대화 + 최대 CPC 한도
5주차~    최근 30일 주요 전환 20~30건 이상 → 전환수 최대화 실험
안정 후   구매·계약 가치가 안정적으로 들어오면 → 가치 기반 입찰 검토
```

### 헬로벨 P-Max — 이번 출시에는 포함하지 않습니다

최근 2년 P-Max 는 ROAS 0.638로 검색(0.011)보다 나아 보이지만,
**전환가치의 88.7%가 2026년 4월 단 3건에서 나왔습니다.**
4월을 빼면 ROAS 0.035로 검색과 차이가 거의 없습니다.
다만 CPA 는 38,244원(4월 제외 42,963원)으로 검색 138,634원보다
3배 이상 낫습니다. **건수 효율은 신뢰할 만하고 가치는 신뢰할 수 없습니다.**

시작 조건

- [ ] 주문번호·구매금액 추적이 30일간 정상 동작 확인
- [ ] 검색 캠페인에서 월 전환 20건 이상 확보
- [ ] 별도 예산 확보 (검색 예산에서 빼지 않음)

설정 시

- 입찰: 전환 가치 극대화, **초기 목표 ROAS 설정 안 함**
- 최종 URL 확장 **사용 안 함**
- 브랜드 제외 목록 적용 / 경쟁사명은 검색 테마에 넣지 않음
- URL 제외: Q&A, 회사 소개, 정책, 로그인, 장바구니, 품절 페이지
- 애셋 그룹: `개인·가정` / `시설·기관` / `공공화장실`

### 헬로클릭 P-Max — 만들지 않습니다

최근 60일 적격 리드 15~20건 이상 + CRM 오프라인 전환 정상 유입,
두 조건이 모두 충족되기 전에는 생성하지 않습니다.
