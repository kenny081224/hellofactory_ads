## 결론

**v4의 판단은 대체로 옳고, 숫자는 전부 정확합니다. 이대로 진행해도 됩니다.**
다만 **진행 전에 반드시 손봐야 할 것 3개**와 조정하면 좋을 것 4개가 있습니다.

| | 항목 | 성격 |
| --- | --- | --- |
| 🔴 1 | 경쟁사·화재·도어벨 제외 키워드가 빠졌습니다 | **필수** |
| 🔴 2 | 헬로클릭 문의 랜딩이 아직 없습니다 | **필수** |
| 🔴 3 | 자동 적용 추천 / 검색 파트너 설정이 빠졌습니다 | **필수** |
| 🟡 4 | 헬로클릭 20,000원이 인벤토리에 맞습니다 (30,000원은 과다) | 조정 |
| 🟡 5 | `[안심벨]`은 Core 가 아니라 Care 로 | 조정 |
| 🟡 6 | 제 문안에 확인 안 된 사양이 13곳 있었습니다 | 수정 완료 |
| 🟡 7 | 매장·식당용 호출벨 판매 여부 확인이 먼저입니다 | 확인 |

## 1. 숫자 검증 — 전부 일치

v4가 제시한 광고비를 원본 CSV로 다시 계산했습니다.

| 항목 | v4 주장 | 검증 |
| --- | ---: | --- |
| 2026년 1~7월 합계 | 937,899원 | ✅ |
| 1~7월 평균 | 133,985.57원 | ✅ |
| 2~7월 평균 (1월 제외) | 155,344.50원 | ✅ |
| 600,000 ÷ 1~7월 평균 | 4.48배 | ✅ |
| 600,000 ÷ 2~7월 평균 | 3.86배 | ✅ |

월별 7개 값도 하나씩 대조해 모두 일치했습니다.

**결론: 월 60만 원 즉시 집행을 말린 v4의 판단이 옳습니다.**
제가 v2에서 제안한 60만 원은 근거가 약했고, v3에서 20만 원으로 내렸지만
"상한/활성/예비" 구분까지는 못 했습니다. v4 방식이 낫습니다.

## 2. v4가 잡아낸 제 문서의 오류 — 사실입니다

### ① v3 예산 설명이 이전 버전 문구로 남아 있었습니다

> "예산표는 헬로클릭 3%인데 하단 설명에는 행사렌탈 28%, 기업구매 16%,
> 브랜드 6% 등 이전 버전 문구가 남아 있어 서로 맞지 않는다."

확인 결과 **사실입니다.** 생성 스크립트의 "왜 이 배분인가" 블록에 v2 수치가
하드코딩되어 있었습니다. v5에서 검색 인벤토리 기준 표로 교체했습니다.

### ② CPC 경쟁 설명이 부정확했습니다

> "기존 캠페인과 새 캠페인이 같은 검색어를 포함한다고 해서 두 광고가
> 경매에서 서로 직접 경쟁해 CPC가 두 배가 되는 것은 아니다."

맞습니다. Google 은 한 광고주당 한 개 광고만 경매에 올립니다.
같은 키워드가 여러 캠페인에 있으면 **경쟁이 아니라 라우팅과 학습 분산**이
문제입니다. v5에서 표현을 고쳤습니다. 전환일에 기존 캠페인을 일시중지하는
운영 원칙은 그대로 유지합니다.

### ③ 매치타입 중복 설명도 같은 이유로 수정

"정확·구문이 서로 입찰 경쟁한다"가 아니라 "작은 예산에서 데이터가 분산된다"가
정확한 이유입니다.

## 3. 🔴 반드시 보완해야 할 것

### 3-1. 제외 키워드가 너무 얇습니다

v4의 제외어는 35개입니다. **정확일치·구문일치만 쓰니 괜찮을 것 같지만
Google 은 정확일치도 유사 변형(close variants)을 매칭합니다.**

실제 증거가 계정에 있습니다.

| 최근 2년 발생 검색어 | 비용 | 전환 |
| --- | ---: | ---: |
| 씨스 콜 | 156,090원 | 2 (CPA 78,045원) |
| 링고 벨 | 75,403원 | 3 |
| syscall 호출 벨 | 36,780원 | 0 |
| **경쟁사 합계** | **264,038원** | CPA 79,898원 |

`씨스 콜`은 **계정에서 가장 비싼 단일 검색어**였습니다.
`[호출벨]` 정확일치를 등록하면 "시스콜 호출벨" 같은 쿼리가 유사 변형으로
매칭될 수 있습니다. 제외어 없이는 못 막습니다.

**v4에서 빠진 필수 제외어**

```
경쟁사   씨스콜 · 시스콜 · syscall · 링고벨 · 링고 · ringo
화재소방 화재 · 화재경보기 · 소방 · 감지기 · 소화기 · 발신기
다른제품 도어벨 · 초인종 · 인터폰 · 도어락
벨소리   벨소리 · 효과음 · mp3 · 수신 감도 · 수신 거부
교차오염 투표 · 퀴즈 · 골든벨   (헬로벨 캠페인에)
```

v5에서 헬로벨 48개 / 계정 20개 / 호출벨그룹 8개 / 헬로클릭 54개 = **130개**로
보강했습니다.

한편 **v4의 "무료·중고·도매·부품을 계정 전체에서 일괄 차단하지 말라"는
지적은 채택했습니다.** B2B 대량구매 의도를 같이 막을 수 있습니다.
계정 공통에서 빼고 캠페인별로만 적용합니다.

### 3-2. 헬로클릭 문의 랜딩이 아직 없습니다

v4 §13-3에 "랜딩을 구분한다"고만 되어 있는데, **지금 그 페이지가 존재하지
않습니다.** 받을 곳이 없는 상태로 8주를 태우면 20,000원 × 2개월을 쓰고도
판단 근거가 남지 않습니다.

→ v5: **랜딩이 준비될 때까지 `HC_Intent_Test` 는 일시중지 상태로 둡니다.**
헬로벨 3개 캠페인만 먼저 시작하세요.

### 3-3. 계정 설정 2개가 빠졌습니다

| 설정 | v4 | 왜 필요한가 |
| --- | --- | --- |
| 검색 파트너 | 언급 없음 | **첫 30일 OFF.** 파트너 지면은 의도가 흐리고 성과 분리가 어렵습니다 |
| 자동 적용 추천 | 언급 없음 | **전부 OFF.** 켜져 있으면 Google 이 확장검색 키워드를 임의로 추가합니다 |

두 번째가 특히 중요합니다. 기존 계정의 키워드 106개가 **전부 확장검색**이었던
것도 이 기능이 켜져 있었을 가능성이 있습니다. 확장검색을 안 쓰기로 해놓고
자동 추천을 켜두면 도로 원위치됩니다.

## 4. 🟡 조정하면 좋을 것

### 4-1. 헬로클릭 30,000원 → 20,000원

v4의 "월 6,000원으로는 실험이 불가능하다"는 지적은 맞습니다.
다만 30,000원은 **인벤토리를 초과합니다.**

v4가 제시한 키워드플래너 수치로 계산하면 이렇습니다.

| 캠페인 | 월 검색량 합 | v4 예산 | 검색 1회당 |
| --- | ---: | ---: | ---: |
| Core | 1,760 | 80,000원 | 45원 |
| Care | 460 | 45,000원 | 98원 |
| Facility | 380 | 25,000원 | 66원 |
| **HC** | **90** | **30,000원** | **333원** |

HC 는 Core 의 **7.3배**, Facility 의 **5.1배**입니다.
검색량 90회에 정확·구문일치만 쓰면 실제 노출은 그보다 적고, 클릭은
월 8~10회 수준입니다. CPC 2,300원이면 **월 20,000원 안팎이 상한**입니다.

30,000원을 넣어도 다 소진되지 않으니 손실은 아닙니다. 다만 그만큼
**Facility 가 굶습니다.** Facility 는 검색량 380회로 인벤토리가 4배 크고,
`병원 호출벨`(110회)을 승격하기로 한 것도 v4 본인의 결정입니다.

→ v5: **HC 20,000원 / Facility 35,000원.** 활성 합계는 180,000원 그대로입니다.
8주 최대 손실도 60,000원 → 40,000원으로 줄어듭니다.

### 4-2. `[안심벨]`은 Care 로

v4는 `[안심벨]`을 `AG_비상벨_핵심`(Core)에 넣었습니다.
v3에서는 `AG_노인안심벨`(Care)에 있던 것을 옮긴 것인데, **후퇴입니다.**

- "안심벨" 검색자는 대부분 노인·보호자 의도입니다
- Core 의 RSA 는 무선 비상벨 문안이라 안심벨 검색자에게 안 맞습니다
- 최근 2년 실적에서 `노인 안심벨` CPA 7,042원으로 **계정 최고 효율**이었습니다

키워드플래너 210회는 Care 에서 가장 큰 키워드가 됩니다.
→ v5: Care 의 `AG_노인안심벨` 로 이동.

### 4-3. 제 문안에 확인 안 된 사양이 13곳 있었습니다

v4의 "확인되지 않은 사양·인증·실적·보증 문구는 사용하지 않는다"는 원칙을
제 v3 문안에 적용해 보니 **13곳이 걸렸습니다.**

| 표현 | 문제 |
| --- | --- |
| `방수 버튼 사용`, `욕실에도 방수 설치` | 헬로벨 자료에 방수 등급 없음. **IPX6 는 헬로클릭 사양** |
| `배터리 2년 사용` | 헬로벨 자료에 배터리 수명 없음. **AAA 2년은 헬로클릭 사양** |
| `정품 A/S 보장` | 자료에 A/S 조건 없음 |
| `관공서 학교 납품` | 학교 설치 사진은 있으나 납품 실적 표기 없음 |
| `세금계산서 발행` | 자료 근거 없음 (사실이면 바로 사용 가능) |

제가 헬로클릭 사양을 헬로벨에 잘못 적용한 것입니다.
→ v5: 전부 제거하고 중립 문구로 교체. **생성 스크립트에 금지어 검사를
추가**해 재발을 막았습니다. 사실로 확인되면 되살립니다 (승인 항목 6번).

### 4-4. 야간 노출 확대 시 전환 해석 주의

v4의 "웹 문의는 06~24시, 전화 애셋만 업무시간"은 맞습니다.
다만 **주요 전환에 `HB_전화_적격`(60초 이상 통화)이 들어 있습니다.**

야간 트래픽은 전화 전환이 구조적으로 안 잡히므로, 4주차에 시간대별 성과를
볼 때 **야간이 실제보다 나빠 보입니다.** 폼 문의만으로 비교하거나 전화 전환을
빼고 봐야 합니다. v5 §11에 주석으로 넣었습니다.

## 5. ❓ 진행 전에 답이 필요한 것 하나

### 매장·식당용 호출벨도 판매하십니까?

v4는 `AG_호출벨_검증`에 `식당 · 카페 · 주문벨 · 테이블벨 · 진동벨 · 웨이팅벨`을
제외어로 넣자고 했고, "제품과 맞지 않는다는 확인 후 적용"이라는 단서를 달았습니다.
**이 단서가 핵심입니다.**

- 헬로팩토리의 원래 주력은 **레스토랑 스마트 호출벨(헬로벨)** 입니다
- 제품 자료 p6도 "서비스 공간의 거리 제약", "고객의 호출 이후 처리 여부"라는
  **매장 시나리오**로 문제를 정의합니다
- 자사몰 이름 자체가 `hellobell.shop` 입니다

**매장용 호출벨을 팔고 있다면 이 제외어를 넣으면 안 됩니다.**
오히려 `식당 호출벨` `카페 호출벨` `테이블 호출벨`을 키워드로 **확장**해야
합니다. `호출벨` 월 480회의 상당 부분이 여기일 가능성이 큽니다.

→ v5: 제외어를 `호출벨그룹_제외` 라는 **별도 목록**으로 분리하고,
"적용 전 확인" 경고를 붙였습니다. 판매한다면 목록을 연결하지 마세요.

## 6. v4에서 그대로 채택한 것

- 예산 **상한 200,000 / 활성 180,000 / 예비 20,000** 분리
- 월 60만 원까지의 **4단계 확대 게이트** (조건 충족 시에만)
- **헤드라인 위치 고정 해제** — 트래픽이 적을 때 고정하면 조합 학습이 막힘
- **병원 호출벨 승격** (키워드플래너 월 110회)
- **응급안전안심서비스 월 5,000원 한도** + 구매 의도 30% 미만 시 중지
- **전환 가치 임의 입력 금지** — 매출·마진 확정 전까지 클릭수 최대화만
- 광고 노출 06~24시, 전화 애셋만 업무시간
- 헬로클릭 8주 존치 판정 기준 (적격 문의 1건 / 누적 클릭 15회 / 거래 의도 50%)
- 리드 양식 필수 항목 (개인·시설 구분, 사용 장소, 예상 수량, 설치 시기)
- 네이버 데이터랩보다 **키워드플래너 절대 검색량을 우선**한다는 원칙

특히 마지막 항목은 제 v3 결론 하나를 바로잡았습니다.
v3에서 "헬로클릭 검색 수요가 사실상 없다"고 했는데, 키워드플래너로
`전자투표기 50 · 무선투표기 30 · 청중응답시스템 10`이 확인되었습니다.
**"없다"가 아니라 "작다"가 맞습니다.** 표현을 완화했습니다.

## 8. 진행 순서

```
지금       ① 제외 키워드 130개로 보강        ← 3-1
           ② 자동 적용 추천 OFF, 검색 파트너 OFF  ← 3-3
           ③ 매장 호출벨 판매 여부 확인       ← 5장
           ④ 제품 사양 5종 확인 (방수/배터리/AS/실적/세금계산서)

1주차      전환 태그 + CRM 연동 검증
2주차      헬로벨 3개 캠페인만 활성화        ← HC 는 랜딩 대기
           첫 2주 검색어 매일 확인
헬로클릭   랜딩 완성 후 별도 시작 → 8주 판정
4주차      예산 게이트 1단계 판정
```
