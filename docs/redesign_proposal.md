## 0. 요약

제품 자료를 읽고 나니 **지금까지의 광고는 제품의 핵심 가치를 한 번도 말하지 않았습니다.**

| | 실제 제품 | 광고가 말해온 것 |
| --- | --- | --- |
| 헬로벨 | 버튼별로 **메시지와 수신자를 지정**하고, **누가 처리했는지 상태를 공유**하며, **배터리 잔량을 원격 확인**하는 플랫폼 | "원격 수신 가능한 스마트 비상벨" (= 무선벨) |
| 헬로클릭 | **온·오프라인 동시 집계**되는 청중응답시스템. 연결 대수 무제한, 수신거리 80M, 배터리 2년 | "학생응답시스템" (= 교육용 클리커) |

두 제품 모두 **경쟁 제품의 구체적 결함을 해결한 것이 팔 거리**인데, 광고 문안에는
그 결함도 해결책도 없었습니다. 그래서 "무선 비상벨" "학생응답시스템" 같은
카테고리 일반어로만 경쟁했고, 카테고리 일반어는 CPC가 비싸고 의도가 섞입니다.

이번 재설계의 뼈대는 하나입니다. **제품 자료에 적힌 경쟁사 결함을 그대로
키워드와 광고 문안으로 옮긴다.**

## 1. 자료에서 확인한 제품 사실

### 1-1. 헬로벨 — 파는 것은 '벨'이 아니라 '전달·처리 플랫폼'

자료 p6이 기존 호출벨의 한계를 세 가지로 정리하고 있습니다. 이게 그대로 소구점입니다.

| 기존 제품의 문제 (자료 p6) | 헬로벨의 해결 | 광고에서 쓸 말 |
| --- | --- | --- |
| 고정 위치에서만 확인, 신호 도달거리 내에서만 수신 | 스마트폰·스마트워치로 어디서나 | "수신거리 제한 없음" |
| '띵동' + 번호만 표시, 다른 메시지 전달 불가 | **벨마다 메시지와 수신자 지정** | "어느 칸인지 문구로" |
| 호출 이후 처리 여부 확인 불가, 수신자 지정 불가 | **요청 수락 → 상태 공유** | "누가 처리했는지 공유" |

여기에 자료 p5의 한 문장이 공공시설 영업의 핵심입니다.

> "담당자 부재, 배터리 방전 등의 이유로 기존 비상벨 제품 설치 효과 제한적"

그리고 대시보드가 **배터리 잔량과 수신기 연결 여부를 확인**해 줍니다(p12).
즉 "설치해 놓고 방치되는 비상벨" 문제에 대한 정확한 반박을 제품이 가지고 있는데
광고에서 한 번도 쓰지 않았습니다.

**시스템 구성** (p9): 송신기 → 전용 수신기(안드로이드 태블릿) → 와이파이 → 헬로벨 서버
→ 스마트폰/스마트워치/대시보드

**타깃 시나리오** (p8, p13): 관리자 / 보호자 / **지자체 모니터링·통계** / 돌봄서비스 담당자.
독거노인 낙상 시 보호자 2명 + 독거노인종합지원센터 + 돌봄 담당자가 **동시에** 인지.

**낙상 통계** (p3): 어르신 사망 원인의 약 5%. 65세 이상 63%, 총 23,561건.
발생 장소 **주택 74%**, 그중 방·욕실 36.4% / 거실·주방 24.7%.
→ 광고 설명문에 그대로 쓸 수 있는 숫자입니다.

**인증·권리** (p14, p15): KC·FCC·CE 인증, 특허 국내 11건 + 해외 12건,
디자인 국내 15 / 해외 7, 상표 국내 18 / 해외 4.
→ 관공서 담당자에게는 이게 신뢰 신호입니다.

## 2. 이전 분석 정정 2건

자료를 보고 나서 제가 앞서 드린 판단 두 가지를 바로잡습니다.

### 정정 ① "독거노인·낙상사고는 낭비 키워드다" → 틀렸습니다

3년 데이터에서 '독거노인' 748,128원 CPA 149,626원, '낙상사고' 78,885원 전환 0을 보고
제외 키워드로 분류했습니다. 그런데 **자료 p13의 대표 적용 예시가 바로 독거노인 낙상**입니다.

문제는 주제가 아니라 **매치타입과 랜딩**이었습니다.
- '독거노인' 확장검색 → "독거노인 돌봄 서비스", "독거노인 종합 지원 센터",
  "독거노인 신청" 같은 **복지 수급 정보를 찾는 사람**이 들어왔습니다
- 이들은 제품 구매자가 아니라 **지자체 사업의 수혜자/신청자**입니다
- 정작 사야 할 사람은 **지자체 담당 공무원과 돌봄센터**인데, 그들이 쓰는 말
  ("응급안전안심서비스", "재가 어르신 응급벨")로는 광고가 없었습니다

→ 제외가 아니라 **B2G 세그먼트로 분리하고 정확일치로 좁힌다**가 맞습니다.

### 정정 ② "투표 키워드는 전면 제외한다" → 조건부로 틀렸습니다

최근 2년 투표 키워드 766,191원 / 전환 0을 근거로 전면 제외를 권했습니다.
**타깃을 행사·렌탈로 바꾸신다면 이 판단은 뒤집힙니다.** 투표는 오히려 본류입니다.

다만 전환 0이었던 이유는 분명히 짚고 가야 합니다.

| 등록했던 키워드 | 실제 검색 의도 | 결과 |
| --- | --- | --- |
| 투표 시스템 (확장) | 무료 웹 투표 서비스 | 398,216원 / 0전환 |
| 온라인 투표 (확장) | 네이버·구글폼 같은 무료 도구 | 63,742원 / 0전환 |
| 전자 투표 (확장) | 공직선거·조합 전자투표 제도 | 131,941원 / 0전환 |
| 실시간 투표 (확장) | 방송·팬 투표 | 154,197원 / 0전환 |

**전부 "소프트웨어를 무료로 쓰려는 사람"입니다. 하드웨어를 대여·구매하려는
사람과는 다른 집단입니다.** 이 둘은 키워드 수준에서 갈라야 합니다.

가르는 기준은 단순합니다 — **"대여 / 렌탈 / 구매 / 장비 / 투표기"가 붙었는가.**

```
막을 것:  투표 시스템 · 온라인 투표 · 전자 투표 · 실시간 투표   (광의 단독어)
살릴 것:  무선투표기 대여 · 전자투표기 렌탈 · 총회 투표 장비 · 청중응답시스템 대여
```

기술적으로는 **광의 단독어를 '정확일치 제외'로 막으면** 뒤에 수식어가 붙은
롱테일은 살아남습니다. `[온라인 투표]`를 정확일치로 제외해도
"온라인 투표 시스템 대여"는 계속 노출됩니다.

### 6-3. 입찰 정책

```
1~4주차   클릭수 최대화 + 상한 CPC 900원   → 검색어·전환 데이터 수집
          (전환 추적이 죽어 있는 상태에서 스마트 입찰은 근거 없이 입찰합니다)

5주차~    캠페인당 월 전환 15건 이상 →  전환수 최대화 (타겟 CPA)
          전환가치가 실제 매출로 수집됨 → 전환가치 최대화 (타겟 ROAS)
```

**매치타입:** 시작은 **정확일치 + 구문일치만**. 확장검색은 4주간 검색어를 본 뒤
전환이 확인된 주제에 한해 부분적으로만 엽니다. (기존 106개 전부 확장검색이
지금 문제의 절반입니다)

**기기 입찰:** 검색 캠페인 모바일 **-30%** 로 시작.
최근 2년 검색 CPA가 모바일 92,901원 / PC 27,578원으로 3.4배 차이입니다.

**광고 일정:** 토요일 -50%, 오전 8~9시 -40%. (토요일 176,246원 전환 0,
오전 8~9시 837,254원 전환 1건)

- **비즈니스 로고 / 업체명** — 유지 (로고 CTR 2.92%로 양호)

## 8. 랜딩·전환 설계

### 8-1. 랜딩

현재 검색 광고가 **25개월째 스마트스토어 상품 페이지**로 가고 있습니다.
스마트스토어는 전환 태그 설치가 불가능하므로 이 구조로는 성과를 영원히 못 봅니다.

| 세그먼트 | 권장 도착지 | 이유 |
| --- | --- | --- |
| S1 지자체·돌봄 | 자사몰 또는 전용 랜딩 | 구매가 아니라 **견적·조달 문의**가 목표 |
| S2 공공시설 | 자사몰 비상벨 상품 | 견적 + 소량 구매 혼재 |
| S3 요양·의료 | 자사몰 비상벨 상품 | 대량 견적 |
| S4 가정·보호자 | 자사몰 비상벨 상품 | 직접 구매 |
| C1~C4 헬로클릭 | **렌탈 문의 랜딩 필요** | 자사몰에 대여 동선이 없음 |

> **헬로클릭 렌탈은 지금 받을 페이지가 없습니다.** "인원 / 일정 / 대여·구매"를
> 묻는 간단한 폼 하나가 먼저 있어야 캠페인을 켜는 의미가 있습니다.

### 8-2. 전환 액션

```
구매_헬로벨        (자사몰 주문완료, 값=결제금액)      주요 전환
구매_헬로클릭      (자사몰 주문완료, 값=결제금액)      주요 전환
견적문의_헬로벨    (폼 제출, 고정값)                   주요 전환
대여문의_헬로클릭  (폼 제출, 고정값)                   주요 전환
전화클릭           (tel: 링크)                         주요 전환
장바구니담기       —                                    보조(관찰용)
```

**캠페인마다 '이 캠페인에 대해 전환 액션 선택'을 반드시 지정하세요.**
안 그러면 헬로클릭 캠페인이 헬로벨 매출을 자기 성과로 착각합니다.

## 9. 운영 정책

### 절대 규칙

1. **측정이 정상화되기 전에는 예산을 올리지 않는다.**
   지금 25개월 중 17개월이 전환 0입니다. 이 상태에서 증액은 손실을 키우는 것뿐입니다.
2. **한 번에 한 변수만 바꾼다.** 예산·입찰·문안을 같이 바꾸면 원인을 못 찾습니다.
3. **확장검색은 4주간의 검색어 검토 없이 열지 않는다.**
4. **성과가 나쁜 키워드는 삭제하지 않고 일시중지한다.** 이력이 남아야 합니다.
5. **계정을 바꾸면 저장소도 같이 바꾼다.** `plan.yaml` / `ads.yaml`이 실제와
   어긋나면 다음 분석이 전부 틀어집니다.

### 주기별 루틴

| 주기 | 할 일 |
| --- | --- |
| 매주 (15분) | 검색어 리포트 → 제외 키워드 등록 / 전환 발생 검색어를 정확일치 승격 |
| 매주 | 전환 액션 상태가 '최근 전환 기록됨'인지 확인 ← **이번 사태의 재발 방지** |
| 격주 (30분) | 애셋 실적 확인, '낮음' 등급 헤드라인 2~3개만 교체 |
| 매월 (1시간) | 월별 추이 확인, 예산 재배분, 입찰 전략 승급 판단 |
| 분기 | 시즌 반영 — 헬로클릭 행사 성수기(3~6월, 9~11월), 아파트 정기총회(11~12월) |

### 판단 기준선

| 항목 | 값 | 근거 |
| --- | ---: | --- |
| 목표 CPA (헬로벨) | 30,000원 | 최근 2년 최고 효율 구간 7,042~29,008원 |
| 목표 CPA (헬로클릭) | 50,000원 | 렌탈 객단가 미확인, 잠정치 |
| CTR 하한선 | 3% | 현재 0.61%로 심각 |
| 낭비 판정 | 전환 0 + 클릭 20회 | 기존 기준 유지 |
| 판단 유보 | 클릭 30회 미만 | 표본 부족 |

```
       ↓ 이게 안 되면 아래는 전부 의미 없습니다

2주차  새 캠페인 업로드(일시중지) 키워드·문안·URL 눈으로 검수
3주차  기존 캠페인과 교체         새 캠페인 사용 설정 → 기존 일시중지(삭제 금지)

```

## 11. 적용 전 확인이 필요한 것

제가 자료만으로는 결정할 수 없어 답을 주셔야 하는 항목입니다.

1. **월 예산** — A/B/C안 중 어느 쪽인가요. 위 설계는 B안(월 60만원) 기준입니다.
2. **헬로클릭 렌탈 가격 체계** — 일 단위인지 행사 건당인지, 최소 수량이 있는지.
   광고 문안에 가격을 쓸지 말지가 여기서 갈립니다.
3. **렌탈 문의를 받을 페이지** — 만들 계획이 있으신지, 아니면 전화·카톡으로만 받으실지.
4. **헬로벨 지자체 납품 실적** — 광고에 "지자체 납품 실적"을 쓰려면 실제 사례가
   있어야 합니다. 자료에는 명시가 없어 확인이 필요합니다.
5. **교육(학교) 유지 여부** — 고객 리스트에 학교가 60곳 넘습니다. 완전히 접을지
   소액 유지할지.
